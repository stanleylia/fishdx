# Reproducibility Map — Paper ↔ Code

> Supplementary reproducibility artefact accompanying the manuscript's
> Supplementary Information: maps each equation, algorithm, hyperparameter,
> and reported KPI to its concrete location in this deposit.

This document maps every equation, algorithm, hyperparameter, and KPI
claim in the manuscript to its concrete `<file>:<line>` location in this
self-contained deposit (`core/` + `src/fishdx/`).

The KPI values below are the manuscript's **evaluation of record**: the
calibration-free **D2-final** set (n = 2,402 = 2,176 shared-class images
+ 226 held-out EUS test images, excluding the 226 EUS calibration images
used to select θ*), plus the field new-disease generalisation set. The
producing scripts and result artefacts are named in §3 and §9. Each
artefact is regenerated by its named script; the deposit's own commit hash
(this release) is the provenance anchor, recorded in `PROVENANCE.txt`.
Reproducing from the shipped `configs/default.yaml`
(seed = 42) is expected to yield numbers within ±0.005 of the reported
values; any deviation outside this band should be reported as an erratum.

## 1 · Equation-to-code map

**What produced the paper's numbers.** The reported empirical results — the
cross-dataset modality comparison, the six-configuration Table 3, the θ_margin
sweep of Table 4, the EUS and new-disease results, and the latency figures — are
produced by the analysis scripts in `scripts/experiments/` operating on the
cached Florence-2/CLIP embeddings in `results/_cache_*.npz` (see §3 and §9). The
`src/fishdx/` package is the end-to-end reference implementation. Headline
retrieval/margin numbers were generated by the named analysis scripts rather
than by invoking this package as a command-line application, but the shared
pareidolia, phrase-matching, scoring, confidence-logging and decision semantics
are aligned with the manuscript definitions below.

Note on scoring (Eqs. 8–9): both the analysis path and `src/fishdx` use
boundary-aware, regular-plural-tolerant phrase presence and credit each
configured keyword at most once. Cross-tier deduplication gives the highest
available tier precedence.

Note on pareidolia (Eq. 1): the reported false-positive-rate numbers
(Supplementary S10) were computed with the **paper-faithful caption-based rule**
(`caption∩K_s ∧ caption∩K_b=∅`) over the real D2 captions
(`results/e3_captions_log.json` → `results/pareidolia_keyword_ablation.json`).
The shipped pipeline code in both `core/algorithms/pareidolia.py` and
`src/fishdx/perception/pareidolia.py` now implements the same caption-based
guard. The archived audit input and output are shipped for direct inspection.

The only component for which **no** faithful implementation exists anywhere in the
codebase is the Algorithm 1 Florence-2 grounding call; the reported penalty
statistic is a retrieval-confidence proxy (see the Algorithm 1 row and note
below). The component ablation of Table S16 is backed by the real retrieval-level
ablations `results/ablation_pareidolia_retrieval.json` (Δ = 0.0) and
`results/ablation_bvl_retrieval_proxy.json` (Δ = −0.0008), not by
`scripts/experiments/exp_e4_component_ablation.py`, which is a non-functional
stub (hardcoded illustrative estimates; its output is not shipped and backs
nothing in the manuscript).

|---|---|---|---|
| 1 | Caption structural hit and no caption biological hit | `core/algorithms/pareidolia.py:detect_hard`; `src/fishdx/perception/pareidolia.py:compute_p_hard`; archived audit in `results/pareidolia_keyword_ablation.json` | Faithful caption-based guard in both public implementations. |

The reported penalty rates (3.4/47.2/94.0%) come from `exp18`. No live Florence-2 grounding call. |

The manuscript's retrieval-confidence-reweighting penalty statistics (penalty rates 3.4% →
47.2% → 94.0% across D1 → D2 → EUS; Mann–Whitney U p = 2.12×10⁻¹⁶⁹, r = 1.000)
were produced by `scripts/experiments/exp18_verification_adversarial.py` and are
archived as `results/verification_penalty_proxy.json`. That penalty is a
**retrieval-confidence proxy** (a candidate is penalised when its top-1 gallery
similarity or top-1/top-2 margin is low), not the live Florence-2 grounding of
Algorithm 1; a faithful Florence-2-grounding implementation is not reconstructable
from the released code. The manuscript Methods and Discussion state this
explicitly. `exp18` reads a large-scale (D8) embedding cache not redistributed in
this deposit; its archival JSON output is shipped so the statistic is traceable.

We additionally validated, on the real model, that the public Florence-2-base
grounding interfaces expose no usable discriminative scalar for candidate
verification. On 210 D2 images, both the true disease phrase and a wrong-class
distractor returned grounding outputs for every image under
`<OPEN_VOCABULARY_DETECTION>` and `<CAPTION_TO_PHRASE_GROUNDING>`, and box-count or
box-area summaries did not reliably favour the true phrase
(`scripts/experiments/exp_florence_grounding_signal_v2.py`,
`results/florence_grounding_signal_v2.json`). The retrieval-confidence proxy is
therefore an operational substitute; the component ablation shows it affects
forced-choice accuracy by only Δ = −0.0008 (Supplementary Table S16).

## 4 · Algorithm 1 line-by-line trace

| Line | Pseudocode (single-pass reweighting) | `src/fishdx` reference-implementation location |
|---|---|---|
| 1 | Caption structural hit and no caption biological hit | `core/algorithms/pareidolia.py:detect_hard`; `src/fishdx/perception/pareidolia.py:compute_p_hard`; archived audit in `results/pareidolia_keyword_ablation.json` | Faithful caption-based guard in both public implementations. |
| 2 | `margin ← sim(c₁) − sim(c₂)` | `reweighting.py` (`margin = s1 − s2`) |
| 3 | `score ← s₁` | `reweighting.py` (`score = cand.similarity × factor`) |
| 4 | `if s₁ < θ_sim or margin < θ_margin then` | `reweighting.py` (`low_confidence = s1 < config.similarity_threshold or margin < config.margin_threshold`) |
| 5 | `score ← score × penalty_factor` | `reweighting.py` (`factor = config.penalty_factor if low_confidence else 1.0`) |
| 6 | drop candidates with `score < min_score` | `reweighting.py` (`if score >= config.min_score`) |
| 7 | return reweighted, re-ranked candidates | `reweighting.py` (`out.sort(...); return out`) |

## 5 · Decision precedence chain (Eq. 10 + Eq. 11)

The implementation extends the paper's three-branch Eq. 10 into a five-step
chain to handle the residual case `S_h > S_d ∧ S_h < T_h`:

| Step | Condition | Outcome | Code |
|---|---|---|---|
| 1 | Caption structural hit and no caption biological hit | `core/algorithms/pareidolia.py:detect_hard`; `src/fishdx/perception/pareidolia.py:compute_p_hard`; archived audit in `results/pareidolia_keyword_ablation.json` | Faithful caption-based guard in both public implementations. |
| 2 | `\|S_h − S_d\| ≤ m` (Eq. 10 row 1) | Inconclusive(scoring_margin) | `decision.py:59-68` |
| 3 | `S_h ≥ T_h ∧ S_h > S_d` (Eq. 10 row 2) | Healthy | `decision.py:70-79` |
| 4 | `S_d > S_h` (Eq. 10 row 3 canonical) | Disease(D_k) where k = argmax_k S_d | `decision.py:81-90` |
| 5 | `S_h > S_d ∧ S_h < T_h` (residual) | Inconclusive(fallback) | `decision.py:92-99` |

Step 5 is documented in the manuscript's Methods §Stage 3. Empirically, it
fires on < 0.3% of D2 queries at the operating point θ_margin = 0.02.

## 9 · How a reviewer reproduces the headline numbers

Each script reads `configs/default.yaml` (seed = 42), resolves the deposit
root from its own location, and writes a JSON artefact under `results/`.
Datasets must be downloaded first into `data/datasets/` (see the
manuscript's Data availability section); the shipped `results/_cache_*.npz`
hold the pre-computed D1-gallery embeddings.

```bash
pip install -e .                     # installs the fishdx package (core/ + src/fishdx importable)

# D2-final evaluation of record (n = 2,402): Table 3 + Table 4 (theta sweep)
python scripts/experiments/exp_d2_final_full.py         # -> results/d2_final_full.json
python scripts/experiments/exp_d2_final_no_calib.py     # -> results/d2_final_no_calib.json  (Decisive DA 0.928, coverage 54.4%)

# EUS theta* calibration (226 calib / 226 held-out test) + interception 71.2%
python scripts/experiments/exp_eus_theta_calibration.py # -> results/eus_theta_calibration.json

# Gradient-free EUS onboarding curve (DA 0.696 @ n_ref=50)
python scripts/experiments/exp_eus_onboarding_modality.py

# New-disease field OOD interception (69.5%) + onboarding
python scripts/experiments/exp_newdx_ood_interception.py
python scripts/experiments/exp_external_validation.py

# Latency / VRAM (median 559 ms, peak ~1.2 GB) on the reference RTX 3070
python scripts/experiments/exp_eus56_margin_and_latency.py
```

Each result JSON holds the values used in the corresponding manuscript
table/figure; compare against §3 to confirm the reported KPIs.
